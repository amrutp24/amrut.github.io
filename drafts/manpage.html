Name

amrut - DevOps / platform engineer; keeps infrastructure boring

Synopsis

amrut [--cloud aws|gcp|azure] [--iac terraform|pulumi] [--k8s] [OPTION]...
amrut --contact

Description

amrut builds and operates the layer underneath the product: clusters, pipelines, cloud accounts and the on-call rota. Given a system that only works when the steps are run in the right order by the one person who knows them, it converts the steps into code that can be reviewed, tested and rolled back.

Started, like most, with a folder of shell scripts and an SSH key. Most of the work since has been closing that gap: declarative infrastructure instead of a runbook, a pipeline instead of a checklist, alerts that mean something instead of a dashboard nobody opens.

Defaults are conservative. Novelty is opt-in. A good deploy is one that is uneventful on a Friday afternoon.

Options

Cloud
-a, --aws
Primary. Landing zones, account structure, networking and identity. Solutions Architect – Professional.
-g, --gcp
Professional Cloud Architect. Projects, VPC design, GKE.
-z, --azure
Mostly the hybrid and identity cases nobody planned for.
Orchestration
-k, --kubernetes
Certified Kubernetes Administrator. Cluster design and day-two operations: upgrades, autoscaling, resource limits that reflect reality.
--helm, --kustomize
Packaging. Prefers fewer templates over cleverer ones.
--gitops
ArgoCD as the only way into a cluster. No kubectl apply from laptops.
Infrastructure as code
-t, --terraform
HashiCorp Certified Associate. Modules other teams can actually reuse; state kept somewhere sane; plan output short enough that people read it before approving.
--pulumi, --cloudformation
When the team already speaks them.
--ansible
For the machines that still exist.
Delivery and observability
--ci github-actions|jenkins
Pipelines that fail loudly and early. Reusable templates so the same Jenkinsfile is not copy-pasted a sixth time.
--observe prometheus|grafana|elk
The metrics, logs and traces needed to answer "what changed?" without guessing.
Languages
--lang python|bash|go
Python for tooling, Bash for glue, Go when it has to be a single binary.

Examples

Stand up a production-shaped AWS environment from nothing:
amrut --aws --terraform --module=landing-zone
Take a forty-minute deploy down to four:
amrut --ci github-actions --gitops --cache-layers
Delete a class of incident instead of fixing it again:
amrut --observe prometheus --postmortem --fix-root-cause
Make the on-call handover a five-minute conversation:
amrut --runbook none --automate-remediation

Bugs

Will occasionally over-engineer when left unsupervised. Holds the opinion that every manual step is a future outage with a delay on it, and will say so in review.

Report bugs to amrut.pagidipally@gmail.com. Include steps to reproduce.
