Selected

  • I blogged about an AWS docs gap. Eight days later, AWS closed it.

    Building a human-in-the-loop agent pipeline on Lambda durable functions turned up an undocumented IAM pattern for callbacks and SDK examples that no longer worked. I wrote it up. The examples were removed and the developer guide gained a callback-permissions page. Timeline included.

    August 2026·Medium·also on AWS Builder Center

  • I wrote a linter for a bug that can't be unit tested

    Durable functions re-run your handler from line one on every resume, so anything outside a step() runs again. Nothing enforces the rule, tests stay green, and the bug surfaces when the workflow next wakes up — up to a year later. So I built replayguard, and validated it against 1,547 files of other people's code.

    September 2026·Medium·also on AWS Builder Center

  • AWS says a production agent is now two API calls. I tested that.

    The smallest real agent on the Bedrock AgentCore managed harness, then managed with Terraform. The two calls work. What they hide: undocumented IAM permissions, roughly 900 tokens of invisible scaffolding on every call, and a state file blind to a billable resource.

    July 2026·AWS Builder Center

replayguard
Determinism checker for Lambda durable functions: static analysis for Python, TypeScript, Java and Rust, plus a harness that runs a handler twice under different clocks and diffs what it did.
